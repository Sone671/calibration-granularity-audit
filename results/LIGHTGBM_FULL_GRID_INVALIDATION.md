# LightGBM 完整网格首轮无效记录

日期：2026-07-29。

首轮 `lightgbm_full_grid/` 完成了协议规定的 140 个环境，但在运行后逐指标复现审计中未能与原冻结的 LightGBM 80%/1h 结果相符。因此该目录不得用于正文、附录或匿名复现包中的任何结论。

根因是首轮 runner 直接使用 0.1 与 0.9 分位数模型的原始输出，而既有冻结 benchmark 通过 `run_validation.predict_three` 对 0.1/0.5/0.9 三个预测逐行排序，以处理量化模型的分位数交叉。两种实现使用相同训练数据、特征、随机种子、训练样本数、树轮数、分群、校准块和评估窗口，但区间端点不等价。

修复仅改为调用冻结基线的 `predict_three`。不改动任何模型参数、训练样本、数据、覆盖率、跨度、分群、校准、指标或结论门槛。修复后的输出将写入独立目录 `lightgbm_full_grid_v2/`，并须再次通过逐指标复现审计后才能使用。首轮目录保留，以便审计。
